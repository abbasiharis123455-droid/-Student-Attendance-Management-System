# 🎓 QR-Based Student Attendance Management System

A smart and efficient solution to automate student attendance in schools and universities using QR Code technology. Built for my **Open Doors Russia Scholarship** portfolio.

### 🚀 Key Features
- **QR Code Attendance:** Each student gets a unique QR code for instant scanning.
- **Real-Time Dashboard:** Teachers can see who is present/absent live.
- **Automated Reports:** Monthly attendance percentage and defaulter list auto-generated.
- **Proxy Prevention:** Stops fake attendance.
- **Secure Database:** All data stored securely using Python & SQLite.

### 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Library:** qrcode, pyzbar

### 🎯 Problem Solved
Manual attendance takes 15-20 minutes of every lecture. This system saves 80% of time and provides 100% accurate data for student performance analysis.

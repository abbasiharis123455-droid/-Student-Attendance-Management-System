QR-Based Student Attendance System - How to Run

1. Install Python 3.8+
2. pip install -r requirements.txt
3. python app.py
4. Open browser: http://127.0.0.1:5000

Features:
- Add Student -> QR Auto Generate
- Mark Attendance by Roll No
- Daily Report
